# Index des guides techniques

Les guides techniques décrivent tout ce qui ne se configure pas directement depuis l'interface graphique.

Ils s'adressent aux exploitants, intégrateurs et développeurs qui doivent installer, configurer ou intégrer la Console dans une plateforme geOrchestra.

## Contenu

- **Administrer** : modèle de données, droits, délégations et points de vigilance d'exploitation.
- **Installer** : architecture, prérequis, lancement local, configuration et tests.
- **Développer** : séparation frontend/backend, matrice fonctionnelle et description des API.

## Principes

- L'interface graphique sert à gérer les utilisateurs, organisations, rôles, délégations et logs.
- Les fichiers de configuration servent à piloter LDAP, PostgreSQL, SMTP, l'en-tête geOrchestra, les règles de mot de passe, la modération, les zones de compétence et les modèles de mails.
- Les API exposent les mêmes objets pour les intégrations techniques.
