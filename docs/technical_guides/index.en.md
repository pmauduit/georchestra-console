# Technical Guides Index

The technical guides describe everything that is not configured directly from the graphical interface.

They are intended for operators, integrators and developers who need to install, configure or integrate the Console into a geOrchestra platform.

## Contents

- **Administration**: data model, rights, delegations and operational points of attention.
- **Installation**: architecture, prerequisites, local startup, configuration and tests.
- **Development**: frontend/backend separation, feature matrix and API description.

## Principles

- The graphical interface is used to manage users, organizations, roles, delegations and logs.
- Configuration files are used to control LDAP, PostgreSQL, SMTP, the geOrchestra header, password rules, moderation, competence areas and mail templates.
- APIs expose the same objects for technical integrations.
